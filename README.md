# 将棋 次の一手クイズ

将棋の局面や戦法に関する問題に答える、Python製のクイズアプリです。

## 概要
複数の問題を順番に出題し、回答後に正誤判定と解説を表示します。
最後に正解数と正答率を表示します。

## 現在の機能
- 複数問題の出題
- 選択肢の番号表示
- 入力値チェック
- 正誤判定
- 解説表示
- 得点集計
- 正答率表示
